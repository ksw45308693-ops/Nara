# 무상 운영 기준

1차 내부 검증은 유료 플러그인과 유료 SaaS를 사용하지 않는다.

| 영역 | 채택 | 비용 조건 |
| --- | --- | --- |
| 애플리케이션 | Go 표준 라이브러리 중심 단일 바이너리 | 라이선스 비용 없음 |
| 데이터베이스 | 자체 운영 PostgreSQL | 라이선스 비용 없음 |
| 프록시·TLS | Nginx + ACME 호환 무료 인증서 | 라이선스·인증서 비용 없음 |
| 공고 데이터 | [공공데이터포털 나라장터 OpenAPI](https://www.data.go.kr/data/15129394/openapi.do?recommendDataYn=Y) | 개발계정 무료 호출량 안에서 사용 |
| 메일 | 회사의 기존 SMTP 또는 자체 운영 메일 서버 | 외부 메일 API를 구매하지 않음 |
| 작업 실행 | Go 프로세스 내부 스케줄러 + PostgreSQL 잠금 | Redis·외부 큐 없음 |
| UI | 서버 렌더링 HTML·내장 CSS·최소 JavaScript | 상용 UI 키트·CDN 없음 |
| 배포 | FreeBSD `rc.d` + Nginx | 컨테이너·상용 배포 플랫폼 없음 |

무료 API 한도를 보호하기 위해 실제 HTTP 시도 수를 PostgreSQL에 일 단위로 기록하고,
서비스 전체 합계가 안전 한도에 도달하면 다음 날까지 수집을 중단한다. 실패 재시도에는
지수 백오프를 적용한다.

기존 서버의 구입비·전기·회선·도메인과 회사 SMTP 운영비는 이 문서의 “소프트웨어 및
외부 서비스 0원” 범위에 포함하지 않는다. 기존 SMTP가 없다면 1차 검증에서는 메일을
테스트 수신 서버로 확인하고, 실제 외부 발송 전에 회사 메일 정책을 확정한다.
